# Dashell RSS 2.7.5

Released November 10, 2026. This release improves finding articles, adding subscriptions and recovering from failed actions, and packages the completed upstream adaptations since 2.7.4.

## Find articles without paging through results

- Search article titles across all pages in the current feed, folder or filtered view. Capitalization and surrounding spaces no longer hide matches.
- Keep the query, result count and filter statistics aligned. A visible Clear search action restores the current view, including when there are no matches.
- Add your first subscription directly from an empty dashboard.
- Open and close the sidebar with Enter or Space, with a visible focus indicator. Closing subscription search clears pending filters and restores focus.

## Understand progress and recover from failures

- Adding a feed now shows explicit progress, locks duplicate submissions, and explains that Close lets the background save continue.
- Failed saves preserve the URL, title and folder so the same form can be retried. Chinese title composition no longer triggers Enter or Escape shortcuts.
- Empty-result messages span the full card grid, including custom six-column layouts. Narrow screens keep cover actions compact and primary toolbar controls at 44px.
- Error text follows the host theme's error color.

## Reading and source improvements

- Selected RSS Dashboard 2.8.0-beta.2 improvements include inherited tag colors and staged palettes, cancellable page-wide cover fetching, article title scaling, optional mobile panel swipes, Twitch routing and Bluesky post extraction.
- Saved Markdown supports longer UTF-8-safe filenames, GFM tables and template image deduplication; preview retries, folder popouts and media action states are improved.
- Selected Qiaomu AI RSS 0.32.8 responsive improvements keep tablet icons visible and improve narrow workbench actions, search and dates.
- Dashell Reader handoff, per-version learning files and the existing shared transport remain in use. Qiaomu's separate speech system is not included.

## Install or upgrade

Update through BRAT, or replace only `main.js`, `manifest.json` and `styles.css` in `.obsidian/plugins/dashell-rss`, then reload the plugin. Preserve `data.json`, feed shards, user state, backups and learning materials. The plugin ID remains `dashell-rss`; the minimum Obsidian version remains 1.8.7. Update Dashell Reader separately if you use its integration.

## Verification and limits

The candidate was tested in Windows Obsidian 1.15.1: existing feeds loaded, normalized search and clearing worked, keyboard sidebar controls worked, an HTTP 503 feed load recovered after correcting the address, a synthetic 25-article subscription saved, and an article was saved to Markdown and read in Dashell Reader. The subscription and saved state survived plugin reload. Test subscriptions were removed afterward, restoring the original four feeds and 109 articles. The six-column empty state was fixed and retested in the host.

Browser component checks cover first-run empty states, cross-page search, save failures and retries, and layouts from 320px to 1600px. Disk permission failures, a full app cold start, physical mobile devices, screen readers and real Windows Chinese input methods remain unverified; synthetic composition events have regression coverage.
