# Dashell RSS 2.7.4

Released October 27, 2026. This release packages the completed Dashell changes since 2.7.3, with selected Qiaomu AI RSS improvements evaluated through 0.32.7.

## Find, add and read sources

- Preview RSS, Atom and JSON feeds by content. Discover declared feeds from a website, choose among multiple results, and open OPML in the existing selection flow. Reuse the downloaded preview when saving a direct feed.
- Cancel or time out outdated previews safely; prevent duplicate Enter/Save submissions and roll back a failed subscription save so it can be retried.
- Navigate article headings with a reading outline that follows the current section and refreshes across original, translated and rewritten versions. Open reading settings directly from the workbench.
- Keep long reading lists bounded while retaining the scroll anchor, variable row heights and Chinese input composition. Start uncached image-cache tasks near the viewport; native image elements may still access the network.

## Reliability and learning exports

- Share prioritized requests through the existing transport, with bounded retry, Retry-After, conditional requests and 304 handling; show cached content first and serialize settings saves.
- Parse Atom fields within their own namespace, including XHTML content.
- Open validated WeChat original-article links in previews and ordinary exports without changing cached source content.
- Recover malformed standalone Markdown images in translated/rewrite exports while retaining code, sanitization and the existing hidden-image preview policy. Saved learning images render in Dashell Reader.
- Restore article and media handoff to the current Dashell Reader and Player plugin IDs. Preserve the Dashboard, pagination, original/translated/rewritten files and their learning state.
- Update DOMPurify to 3.4.17 and patch the locked development Vite/undici dependencies without lowering audit gates.

## Upgrade and verification

The plugin ID remains dashell-rss and the minimum Obsidian version remains 1.8.7. Update through BRAT, or replace only main.js, manifest.json and styles.css in the plugin directory, then reload. Preserve data.json, feed shards, user state, backups and learning files. The attached SBOM describes production dependencies.

Release gates include the complete build, lint, both type checks, platform/architecture/CSS/document checks, the full unit suite with coverage, dependency audits, a source-archive build, and a tagged CI build with provenance and SBOM attestations. Final downloaded assets receive Windows Obsidian upgrade, preview, settings and reload checks, followed by anonymous public-download digest verification.

This GitHub release does not submit Dashell to the Obsidian community directory or claim official review. Qiaomu accounts/server APIs, its podcast catalogue, persistent remote deletion and a second speech/storage/player system are excluded. macOS, physical mobile devices, cold start, two-device sync, real external subscriptions/accounts and new speech synthesis are not covered by this release's host checks.

This is a customized build of [RSS Dashboard](https://github.com/amatya-aditya/obsidian-rss-dashboard). See [NOTICE.md](../../NOTICE.md) for preserved source and license notices.
