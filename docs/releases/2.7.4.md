# Dashell RSS 2.7.4

Opening downloaded learning materials now resolves the current Dashell Reader and Dashell Player plugin IDs, so articles and media can be launched from the learning library again.

## Notable fix

- Fixed the learning library failing to detect installed Dashell Reader and Dashell Player plugins after their plugin IDs changed.

## Compatibility

- **Minimum Obsidian version:** 1.8.7

The complete technical history for this release is available in the [changelog](../../CHANGELOG.md).
