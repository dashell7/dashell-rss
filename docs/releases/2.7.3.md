# Dashell RSS 2.7.3

Dashell RSS connects RSS subscriptions to local English study while preserving the RSS Dashboard feed and media-preview workflow.

- Uses the stable plugin ID `dashell-rss` and identifies Dashell as the maintainer.
- Copies existing feed settings, article state, learning records and backups from `rss-dashboard` or the previous `dshell-rss` plugin folder on first launch; source files remain untouched.
- Saves articles as local Markdown for Dashell Reader, including linked-text handling and separate progress for supplied original, translated, or rewritten versions.
- Keeps podcast and video previews in Dashell RSS.

This is a customized build of [RSS Dashboard](https://github.com/amatya-aditya/obsidian-rss-dashboard). See [NOTICE.md](../../NOTICE.md) for preserved source and license notices.
