## 已适配的能力

| 能力 | Dashell 落点 | 行为 |
| --- | --- | --- |
| Atom 字段校验 | `atom-parser.ts`、`custom-xml-parser.ts` | 只读取 Atom 同命名空间直属字段，媒体字段不冒充正文；支持前缀命名空间与 XHTML。 |
| 请求共享与阅读优先 | `read-request.ts`、`platform-utils.ts` | GET 按地址与请求头共享，统一限制传输并发；为当前阅读保留容量。 |
| 有限重试与冷却 | `read-request.ts`、刷新服务 | 瞬时错误最多重试一次，并有全局重试预算；遵守 Retry-After；自动刷新失败逐步延后。 |
| 条件请求 | `feed-fetch.ts`、`feed-parser-class.ts` | 保存 ETag/Last-Modified；304 沿用正文与用户状态。 |
| 立即显示缓存正文 | `article-renderer.ts` | 缓存先显示，完整正文后台获取；切换文章后迟到结果不覆盖当前页面。 |
| 图片缓存 | `preview-image-cache.ts`、`image-cache-service.ts` | 磁盘缓存立即显示，未缓存的缓存任务在图片接近视口 200px 内启动，后台清理；视图关闭释放观察与事件。原生图片元素仍可自行联网，不宣称所有图片网络均延迟。 |
| 阅读工作台 | `src/dashell/workbench*` | 沿用既有工作台入口，增加搜索、稍后读、来源健康信息与键盘操作。常规首页和媒体预览仍走原路径。 |
| 大列表与中文输入 | `list-window.ts`、`workbench-window.ts`、`workbench.ts` | 可变行高及有界 DOM、视口外预留 6 行、稳定滚动锚点；中文输入法组合期间不筛选，完成后延迟 120ms 搜索。 |
| 保存串行化 | `settings-save-queue.ts`、`settings-store.ts` | 连续保存合并待写批次；恢复设置独立排队；删除订阅不会被早期保存复活。 |

## 保留的产品边界

RSS 首页继续显示 Dashboard 订阅与卡片；文章保存后交给 Dashell Reader；
播客、视频保留原 RSS 预览。Dashell Reader 继续拥有查词、生词学习、AI 和朗读。

不原样接入乔木自有服务器 `/api/entry`、精选源与服务器管理。它们依赖不同服务，
不能替换 Dashell 的通用 RSS/Atom/JSON Feed 传输。不增加第二套词典、生词库、
Anki 同步、正文迁移或传输限流器。
